1 Sebastian (Sep 14): Khovanov Homology

Recall that the Kauffman bracket of a link diagram D has axioms ⟨∅⟩=1, ⟨0⊔D⟩=(q+q−1)⁢⟨D⟩, and for any crossing

⟨crossing⟩=q⁢⟨horizontal⟩+q−1⁢⟨vertical⟩

If D has n+ positive crossings and n− negative crossings, then the Jones polynomial of the underlying link L is J⁡(L)=(−1)n⁢qn+−2⁢n−⁢⟨D⟩.

We may have heard that Khovanov homology is a categorification of the Jones polynomial. To motivate this, there are quantum invariants like the Jones polynomial, the HOMFLY polynomial, WRT, and others. On the other side, there are gauge-theoretic invariants like instanton Floer homology and the Casson invariant. The quantum invariants generally come from representations of quantum groups are are combinatorial, but it is unclear what geometric information we obtain. On the other hand, the gauge theoretic invariants are more powerful, but of course harder to compute. We want to consider relations between the two types of invariants.

Some of the gauge-theoretic invariants end up being Euler characteristics; for example, the Casson invariant is twice the Euler characteristic of instanton Floer homology.

For a link diagram L, we will introduce a bigraded ℤ-module Kh∗,∗⁢(L) such that

J⁡(L)=∑i,j(−1)i⁢qj⁢rkℤ⁡Khi,j⁢(L).

1.1 Category of Pictures

Given D, we will order its crossings. For each crossing we have a 0-resolution (horizontal) and a 1-resolution (vertical). If n=n++n−, then each element of {0,1}n gets a complete resolution, which is a collection of circles in the plane. For example, consider the Hopf link with resolution.

Then we have

⟨H⟩=(q+q−1)2−q⁢(q+q−1)−q⁢(q+q−1)+q2⁢(q+q−1)=q4+q2+1+q−2,

J⁡(H)=(−1)2⁢q−4⁢⟨H⟩=1+q−2+q−4+q−6.

1.2 Khovanov Homology

Returning to something more concrete, any cobordism in 𝖢𝗈𝖻3/ℓ can be decomposed into pairs of pants and caps and cups, so to specify a functor, we only need to specify what it does to four morphisms. Here, the cobordisms correspond to

m:V⊗V→VΔ:V→V⊗Vι:V→ℤε:V→ℤ,

where V=ℱ⁡(S1) for ℱ a TQFT. Then Khovanov homology is the functor where V=ℤ⁢{−1}⊕ℤ⁢{1}, where m is given by

v−⊗v−↦0v−⊗v+↦v−v+⊗v+↦v+v+⊗v−↦v−,

Δ is given by

v−↦v−⊗v−v+↦v+⊗v−+v−⊗v+,

ι is given by 1↦v+, and ε is given by v−↦1,v+↦0. The grading on V is called the Jones grading because it records power of q in the Jones polynomial.

Kh⁡(L)≔H∗⁢(ℱ⁡([[L]]))⁢[−n−]⁢{n+−2⁢n−}

2 Álvaro (Sep 21): HOMFLY-PT homology

If we already know about Hecke algebras, then we could discover the HOMFLY-PT polynomial with the unknot being 1 and the skein relation

t⋅under+t−1⋅over=z⋅unlinked.

Here, if we set t=q2⁢N and z=q+q−1, we recover the S⁢L2 link polynomial and if we set N=1, we recover the Jones polynomial.

The reason that we could have discovered the HOMFLY-PT polynomial is using the representation theory of the braid group, which is generated by s1,…,sn−1 with relations si⁢si+1⁢si=si+1⁢si⁢si+1 and si⁢sj=sj⁢si if |i−j|≥2.

First, note that every link is the closure of a braid. Then two braids give rise to isotopic links if they are related by Markov moves. Now we consider

ℤ⁡[q±]⁢Brn↠H⁡(Sn)=ℤ⁡[q±]⋅{δw∣w∈Sn}/δs2=δs⁢(q−1)+q.

Now we can define a trace map

Tr:⋃n≥1H⁡(Sn)→ℤ⁡[q±,z±]

with the condition that Tr⁡(x⁢sn⁢y)=z⁢Tr⁡(x⁢y) and Tr⁡(1)=1. In particular, these imply that Tr⁡(x⁢y)=Tr⁡(y⁢x), and this is called the Oceanu trace. If we normalize the si, then Tr⁡(x⁢si)=Tr⁡(x⁢si−1). Then under the correct normalization, we obtain the HOMFLY-PT polynomial.

2.1 Triply graded homology

This was discovered by Khovanov-Rozansky in 2004 using matrix factorizations and Khovanov in 2005 using Soergel bimodules. Then work of various subsets of Elias, Hogancamp, and Mellit computed HHH for torus (m,n)-links.

3 Avi (Sep 28): Hilbert Schemes

3.1 Definitions

Let X be a projective variety over a field k=ℂ. For example, if X=ℙn, we in algebraic geometry are interested in projective varieties, which are closed subschemes of X. We are interested in classifying closed subschemes of X, and to do this we will construct a functor Hilb⁡(X) given by

Hilb⁡(X)⁢(T)={Z⊂T×X∣Z→T flat}.

We are interested in the representability of this functor, and unfortunately this functor is not representable in any reasonable way.

For example, consider X=ℙ1. If we consider subschemes with finite support, we obtain the space

⨆nSymn⁢ℙ1=⨆nℙn.

This has infinitely many connected components and is infinite-dimensional in general. This tells us that we want to stratify our functor into pieces.

Now consider Z⊂X=ℙn. Then define graded coordinate ring R=⨁iRi of Z and the function i↦dimRRi. For i≫0, this function equals some polynomial in i. More generally, let ℱ be a quasicoherent sheaf on X. Then we can consider the function

i↦h0⁢(X,ℱ⁡(i)),

and in particular, for i≫0, this function equals the Euler characteristic χ⁡(ℱ⁡(i)) because for i sufficiently large, all twists have vanishing higher cohomology. Finally, χ⁡(ℱ⁡(i)) is a polynomial, which we will call the Hilbert polynomial Pℱ⁢(i).

For a subscheme Z⊂X with ideal sheaf ℐZ⊆𝒪X, we will define PZ=PℐZ. Returning to X=ℙ1, then if Z is a scheme which is n points, then dimH0⁢(X,ℐZ)=n. For the subscheme X, we have h0⁢(X,𝒪X⁢(i))=i+1. We are now able to define the functor

Hilbf⁡(X)⁢(T)≔{Z⊆T×X∣Z→T flat,PZt=f}.

In particular, we have a decomposition

Hilb⁡(X)=⨆fHilbf⁡(X).

In our case, we will focus on 0-dimensional subschemes, and we will denote both the functor and the scheme that represents it as X[n]=Hilbn⁡(X).

Example 3.1.1.

Suppose n=0. All subschemes of T×X with PZt=0 must have empty fibers over T and thus must be empty themselves.

If n=1, then all ideals of colength 1 are maximal ideals, which are the same as closed points of X, so X[1]=X.

When n=2, we are looking for ideals ℐ such that 𝒪X/ℐ has length 2. Thus either this subscheme is supported at two distinct points or a single point. If the support of the subscheme is two distinct points x1≠x2, then at each xi, the ring 𝒪X/ℐ must have length 1. Thus we have a locus (X×X∖Δ)/S2. In the second case, where 𝒪X/ℐ is supported at a single point x, then we have a sequence of inclusions

𝔪x2⊆I⊂𝓂X⊂𝒪X.

Thus we are looking for morphisms φ:𝔪x/𝔪x2→k up to a scalar, so above the point x we have ℙ⁢TX,x, and therefore we have

X[2]=(X×X∖Δ)/S2⊔ℙ⁢TX.

More generally, we have a morphism π:X[n]→Symn⁢X sending a subscheme Z to its support |Z|, called the Hilbert-Chow morphism. If λ=(λ1,…,λr) is a partition of n, we have a stratum Symλ⁡X with fixed multiplicities given by λ. Thus we have

Symn⁡X=⨆λSymλ⁡X,

which induces a stratification of X[n] into pieces Xλ[n].

For example, when λ=(n), we have the Hilbert-Chow morphism

X(n)[n]→𝜋Sym(n)⁡X=X,

and so the fibers are schemes Xp[n] parameterizing length n subschemes of X supported at p.

Example 3.1.2.

When X is a smooth curve, π is actually an isomorphism. This is because all local rings 𝒪X,p are discrete valuation rings, and in particular they have a unique idea of length n. Therefore all fibers of π must be points.

When X is a smooth surface, then X[n] is always smooth, but in fact Hilbert schemes of points are highly singular for n>2 in higher dimension.

3.2 Hilbert schemes of smooth surfaces

Now suppose that X is a smooth surface. Suppose that Z⊆X is supported at a point p with length n. In particular, we have a chain of inclusions

𝔪xn⊆I⊆𝔪xn−1⊂𝒪X,x,

and thus this data is equivalent to I/𝔪xn⊂𝒪X,x/𝔪xn−1. Up to completion, all of this data is independent of both X and x, and in fact

𝒪̂X,x=k⁡[[T1,T2]].

Therefore, Xx[n] is independent of X,x, so we may consider X=𝔸2,x=0. We will see that (𝔸2)0[n] has dimension n−1. In general, we have

dimX(λ1,…,λr)[n] =dimX(λ1)[λ1]+⋯+dimX(λr)[λr]
=dimX+dimXp[λ1]+⋯
=(λ1+1)+⋯+(λr+1)
=n+r.

In particular, dimX[n]=2⁢n.

Now we will compute the tangent space of X[n]. If a subscheme Z is given by an ideal ℐ, we first show that the tangent space to X[n] at ℐ is given by Hom⁡(ℐ,𝒪X/ℐ), and then we can use Hirzebruch-Riemann-Roch. Alternatively, consider the action of Gm×Gm on 𝔸2. This lifts to an action on (𝔸2)[n], and the fixed points are given by monomial ideals. Each monomial ideal corresponds to a Young diagram (just consider all monomials not in the ideal), and of course these are in bijection with partitions of n. If we do some allegedly very elegant combinatorics, we obtain the desired result.

We will now connect Hilbert schemes of surfaces to representation theory. We have the formula of Göttsche, which states that

∑n=0∞∑i=04⁢nbi⁢(X[n])⁢ti⁢qn=∏m=1∞∏j=04(1−(−1)j⁢t2⁢m+j−2⁢qm)−(−1)i⁢bj⁢(X)

and another formula which states that

∑n=0∞χ⁡(X[n])⁢qn=∏j=04(∏m≥1(1−qm))−(−1)i⁢bj⁢(X).

In particular, doing some generatingfunctionology gives us the Betti numbers.

These formulas are similar to those coming from representations of the Heisenberg algebra. In fact, the total cohomology of the Hilbert scheme is a representation of the Heisenberg algebra. We consider the incidence schemes

X[n,ℓ]⊂X[n]×X[n+ℓ]

which classifies subschemes Z1⊂Z2 which differ at a single point x.

3.3 Plane curve singularities

There exists a similar formula to those of Göttsche for smooth curves due to Macdonald, which says that

∑n=0∞χ⁡(C[n])⁢qn=(1−q)−χ⁡(C).

We would like to say something about the LHS, which we will call W⁡(C), in general when C is not smooth. Write C=Csm∪{pi}, where the pi are the singularities of C. Then we have

W⁡(C)=W⁡(Csm)⁢∏n=0∞χ⁡(Cp[n])⁢qn

by the cut-and-paste relation for the Euler characteristic. To make sense of what happens at the singular points, we will consider knot theory.

Near p⊂C⊂ℂ2, we will consider C∩S3, which has real dimension 1 and is therefore a link Lp. We would hope that some knot invariant of Lp will recover the data of the fomula above, and according to the Oblomkov-Shende conjecture, this is true. The conjecture says that

8.1 Affine grassmannians

We will begin with some abstract nonsense discussing affine Grassmannians.

Definition 8.1.1.

An A-family of vector bundles on the formal disc D (or the punctured formal disc D∘) is a projective finitely generated module over A⁡[[t]] (or A⁡((t))).

These give categories 𝖵𝖾𝖼𝗍A⁢(D),𝖵𝖾𝖼𝗍A⁢(D∘).

Definition 8.1.2.

The affine Grassmannian for a group G, denoted GrG is the functor

A↦{A→(P,γ)},

where P is an A-family of G-bundles (𝖱𝖾𝗉⁡(G)→𝖵𝖾𝖼𝗍A⁢(D)) over D and γ is a trivialization of P over D∘.

Example 8.1.3.

If G=G⁢Ln, then GrG⁢Ln⁢(A) the set of finitely generated projecive A⁡[[t]]-submodules of A⁢((t))⊕n such that for some m, we have

tm⁢A⁢[[t]]⊕n⊆M⊆t−m⁢A⁢[[t]]⊕n.
Remark 8.1.4.

We can define GrG⁢Ln≤m to be those M which satisfy the relation for some fixed m. Using this, we may view M as an A⁡[t]/t2⁢m-module satisfying some conditions. Therefore, GrG⁢Ln≤m is a closed subfunctor of Gr⁡(2⁢m⁢n) (which means things inside a 2⁢m⁢n-dimensional vector space).

Remark 8.1.5.

Unfortunately, the affine Grassmannian is not a scheme, but at least it is an inductive limit of schemes.

Now consider g∈G⁡((t))⁢(A). This induces an automorphism of the trivial A-family of G-bundles on D∘, and so there is a natural action

G⁡((t))×GrG→GrG(g,(P,γ))↦(P,g⁢γ).
Remark 8.1.6.

We have a simply transitive action on the fiber by G⁡[[t]], and thus

GrG≅[G⁡((t))/G⁡[[t]]]=[L⁢G/L+⁢G].
Example 8.1.7.

Consider the case of G⁢L1=𝔾m. Then the only data that matters is the power of zn near 0, and so GrG⁢L1⁢(ℂ)≅ℤ.

Now we can give a lattice description. Remember that we are considering t-stabble subspaces of t−m⁢ℂ⁢[[t]]/tm⁢ℂ⁢[[t]]. This has a basis (t−m,t1−m,…,tm−1). But now GrG⁢L1≤m⁢(ℂ) is a union of 2⁢m points, and so in the increasing limit we obtain ℤ.

8.2 Coulomb branches

Definition 8.2.1.

Fix a G-representation N. We will define the space

TNG⁢(ℂ)≔{(P,γ,s)},

where (P,γ) is as before and s is a section of Ptriv×GN over D∘.

This has a subset RNG⊂TNG, where we require s to extend to D and γ−1⁢(s) to extend to a section of P. We will call RNG the BFN space, where BFN is Braverman, Finkelberg, and Nakajima.

Definition 8.2.2.

We define the Coulomb branch algebra to be

Aℏ=H∙G⁡[[t]]⋊ℂ×⁢(RNG).
Example 8.2.3.

Consider G=ℂ× and N=0. Then RNG=GrG, and then we have Heq⁢(ℤ)=ℂ⁡[w,x±].

Example 8.2.4.

Consider G=ℂ× and N the adjoint representation. If the trivialization is simply zn=γ, then we need γ⁢s to have no singularities, and therefore s∈zmax⁡(0,n)⁢ℂ⁢[z]. Therefore

RNG=⨆n∈ℤzmax⁡(0,n)⁢ℂ⁢[z],

and therefore we have

Heq⁢(RNG)≃ℂ⁡[w,x,y]/(w=x⁢y).

If we modify the second ℂ× to act with weight m, we instead obtain ℂ⁡[w,x,y]/(w|m|=x⁢y).

Remark 8.2.5.

For T⊆G, we have (ATℏ)W→A~Gℏ, and after localization, this is an isomorphism.

8.3 Hilbert schemes

Definition 8.3.1.

Fix v∈N⁡((t)), where N is a G-representation. Then the generalized affine Springer fiber is defined by

MvN⁢(ℂ)={g∈G⁡((t))∣g−1⁢v∈N⁡[[t]]}/G⁡[[t]].

The main claim is the following: Let Ĉ be a germ of plane curve singularity. Then there is an Ad⊕V-generalized affine Springer fiber MvAd⊕V such that

MvAd⊕V≃Hilb0⁡C~=Hilb⁡ℂ⁡[[x,t]]/f.

By the Weierstrass preparation theorem, we assume that f⁡(x,t)=xn−an−1⁢xn−1−⋯−a0. Then as ℂ⁡[[t]]-modules, we can identify ℂ⁡[[x,t]]/f=⟨1,x,…,xn−1⟩⁢ℂ⁢[[t]]. Then if R=ℂ⁡[[x,t]]/f, we can identify the fraction field of R with ℂ⁢((t))⊕n,∗.

Unwinding definitions, points in Hilb0⁢(Ĉ) are the same as x-stable, finitely generated, projective ℂ⁡[[t]]-submodules of ℂ⁢((t))⊕n such that there exists m such that

tm⁢ℂ⁢[[t]]⊕n⊂M⊂ℂ⁢[[t]]⊕n.

Then we have

γ=(01001⋱a0a1⋯⋯an−1).

We now choose v=(γ,en), where en corresponds to xn−1. We also need ad⁡(g)⁢γ∈Ad⁡[[t]]. We will also choose g such that for some Λ⊂ℂ⁢[[t]]⊕n,∗, we have ℂ⁢[[t]]n,∗⁢g−1=Λ. This implies that

ℂ⁢[[t]]n,∗⁢g−1⁢γ⊂ℂ⁢[[t]]n,∗⁢g−1,

and so Λ⁢γ⊂Λ. The second condition gives us g−1⁢ei∈ℂ⁢[[t]]n. By definition of the affine Springer fiber, we only need g−1⁢en∈ℂ⁢[[t]]n. This implies that γ⁢ek+1=ek+ak⁢en and so we can induct downwards.
