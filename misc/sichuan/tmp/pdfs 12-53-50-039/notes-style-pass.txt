          2. Intro to log geometry (Tingting Fang and Zijian Han)
2.1. Motivation. In enumerative geometry, we will consider intersection numbers
on compactified moduli spaces. This is going to require our objects to degenerate
in some way, for example for domain curves to be nodal, maps to land in boundary
divisors, or we degenerate the target. In ordinary geometry, we view these as
singular, but in log geometry, there is a way to think of these situations as being
log smooth. In log geometry, we are going to replace functions with the data
of functions and how they vanish on the boundary (or namely the morphism
α : MX → OX ).
Example 2.1. Consider a family of curves (xy = t) over A1 , where the central
fiber is nodal. In log geometry, if we place the divisorial log struction on A1 , then
this family is log smooth.

2.4. Log smoothness.
Definition 2.20. Consider a commutative diagram
                                           ϕ
                                     T0         X
                                       j          f
                                           ψ
                                     T1         Y,
where j is a strict closed immersion (here, this means that MT0 = j∗ MT1 ). A
morphism f : X → Y of fine log schemes is log smooth (resp. log étale) if
   (1) The underlying map f : X → Y is locally of finite presentation;
   (2) For any commutative diagram as above, étale locally on T1 there exists a
       (resp. there exists a unique) morphism g : T1 → X such that ϕ = g ◦ j and

Theorem 2.21. Let f : X → Y be a morphism of fine log schemes. Assume we have a chart
Q → MY where Q is a fine monoid. Then f is log smooth if and only if étale locally on X
there exists a chart for f extending Q → MY satisfying
    (1) The kernel and torsion part of the cokernel of Qgp → Pgp is zero or finite order
         invertible on X;
    (2) The induced morphism X → Y ×Spec Z[Q] Spec Z[P] is étale in the classical sense.

3.3. Moduli of curves and CohFTs. We will denote by Mg,n the moduli space
