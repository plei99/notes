# Fonts served by the notes site

`epigrafica-regular.woff2` and `epigrafica-bold.woff2` are Epigrafica
(Epigrafica-Ortha and Epigrafica-Entona) by Antonis Tsolomitis, after MgOpen
Cosmetica, as distributed in TeX Live, converted to WOFF2 by
`build/epigrafica.py`. Licence: GNU General Public License.

They stand in for Optima, which sets `\mathsf` (styles.css `.sf`), on systems
without it. Optima itself is never served.
