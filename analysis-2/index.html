2.1 Lecture 1 (Jan 22)

We will review measure theory from an abstract perspective and treat the Lebesgue measure as an example.1 Let X be a locally compact topological space.

Definition 1 (Sigma-Algebra). A σ-algebra Σ to be a collection of subsets closed under complement and countable union.

We denote by ℬ the Borel σ-algebra, which is the smallest such containing all open sets. μ is a (non-negative) measure if μ is defined on Σ, the empty set has measure 0, and μ is countably additive.

Remark 2 (Notation). Indexing with a Roman letter means countable and indexing with a Greek letter means uncountable.

Definition 3 (Sigma-finite). A measure μ is σ-finite if μ(X)=∑i=1∞μ(Ei) where each Ei has finite measure.

Definition 4 (Completeness). A measure space (X,Σ,μ) is complete if all subsets of measure zero sets are measurable: μ(B)=0 and A⊂B implies A∈Σ.

Definition 5 (Measurable function). A function f:X→R is measurable if f−1(α,∞) is measurable for all real α.

Given the notion of a measurable function, we can integrate:

Definition 6 (Simple Function). A simple function is a finite linear combination of indicator functions

φ=∑i=1kaiχEi.

We define the integral of a simple function φ=∑i=1kaiχEi to be

∫φ dμ=∑i=1kaiμ(Ei).

Given a nonnegative measurable function f, we define the integral

∫f dμ=sup{∫φ dμ},

where φ ranges over all nonnegative simple functions less than or equal to f almost everywhere.

We also set, for a measurable set E,

∫Ef dμ=∫fχE dμ.

Example 7. Given the trivial sigma-algebra, only constant functions are simple.

Lemma 8. Any measurable f can be approximated from below by ϕk→f with ∫φk dμ→∞.

We observe that Fatou’s Lemma, monotone convergence, and dominated convergence hold.

Lemma 9 (Convergence theorems). If μn→μ setwise on Σ and if fn→f almost everywhere (with respect to μ) on X, then

∫fn dμ→∫f dμ.

The ability to exchange limits and integrals is the motivation behind measure theory, and more broadly, analysis is about exchanging limits.

Definition 10 (Mutually Singular). Two measures μ,ν are mutually singular, written μ⊥ν if there exist disjoint A,B such that X=A⋃B such that μ(B)=ν(A)=0.

Example 11 (Cantor). Consider the Cantor set C and Cantor function fC. Recall that the Cantor function is a continuous surjection from [0,1] to itself and has derivative zero almost everywhere. In particular, fC violates the fundamental theorem of calculus. Define the Cantor measure on the Borel sets in [0,1] the usual way by μC((a,b])=fC(b)−fC(a). We see that μC(C)=1, but λ(C)=C where λ is the Lebesgue measure. Therefore, μC⊥λ on [0,1].

Definition 12 (Absolute Continuity). Given two measure μ,ν, ν is absolutely continuous (ν≪μ) with respect to μ if μ(A)=0 implies that ν(A)=0.

Example 13. Given any nonnegative integrable f with respect to μ, we can define a measure μf(E)=∫Ef dμ. Then μf≪μ.

Theorem 14 (Radon-Nikodym). If ν≪μ on a σ-finite X (with respect to μ), then there exists a non-negative measurable f such that ν=μf. We write f=dνdμ.

Example 15. Let f be monotone increasing. Recall that left and right limits exist everywhere. Then observe that f has at most countably many discontinuities xj and

∑j=1∞f(xj+)−f(xj−)<∞

for xj restricted to a compact set. We can write f=fj+fc where fj encodes the jumps and fc is continuous. Then fc decomposes into fc=fa+fC, where fa is absolutely continuous with respect to the Lebesgue measure, and fC is the “Cantor” part. To extract fa we will consider the points at which f is differentiable. In the end, we will have f=fa+fC+fj, where fa is absolutely continuous, fC is “Cantor,” and fj denotes the jumps. The three induced measures will be mutually singular.

5 Compactness

5.1 Lecture 5 (Feb 5)

The notion of compactness distinguishes the two cases of finite and infinite dimensions. There are two notions of compactness: sequential and topological. A prototypical example of a compact set in ℝ is the closed interval [0,1].

Definition 41 (Sequentially Compact). Let X be a metric space. K⊂X is sequentially compact if every sequence {xk}⊂K has a convergent subsequence with limit in K.

Theorem 42 (Heine-Borel). K⊂ℝd is sequentially compact if and only if it is closed and bounded.

This follows easily from the Bolzano-Weierstrass theorem, which states that every bounded sequence in ℝd has a convergent subsequence. Robin explained the idea of B−W, but I will assume that you already know it. In the context of a metric space, we introduce the notion of “total boundedness.”

B⊂⋃x∈NεBε(x).

Proof. For all n, we extract a finite 1/n-net An. Now let A=⋃n=1∞An, which is countable. We show that A is dense in X.

1.
If ℱ is unbounded, then it is not precompact.
2.
If ℱ is precompact, then it is equicontinuous.
3.
If ℱ is bounded and equicontinuous, then it is precompact.

1.
This one is easy. Build a sequence fn such that ‖fn+1‖≥‖fn‖+1. This sequence is not Cauchy, so there is no convergent subsequence.
2.
