1 Introduction

The B-model has its origins in mirror symmetry, which is a duality of two dimensional superconformal field theories (SCFTs) in physics. These describe the geometry of a mapping space from a surface Σ to a target space X (see Figure 1). The duality gives mathematical predictions which relate symplectic geometry (the A-model) to complex geometry (the B-model).

The interested reader can refer to the speaker’s lectures at the Perimeter Institute on supersymmetry and TQFTs, which are also on Bilibili.

There is a string description via a worldsheet theory, where we consider maps as in Figure 2. This theory is called string field theory. This describes string theory using the language of quantum field theory. The correspondence goes as in Table 1.

We outline some historical developments in both mathematics and physics related to the B-model.

  • •

    In 1992, Zwiebach described a general structure for closed string field theory and discovered that it is described by a string action which contains infinitely many vertices and satisfies the BV master equation, something we will describe later in the language of the B-model. In particular, if we consider the genus 0 closed string field, we will discover a homotopy Lie algebra or an L∞-algebra.

  • •

    In 1997, Zwiebach extended this theory to the open string field, which is described by an A∞-algebra. When coupled with the closed string field, it satisfies the open-closed master equation, which is described via the moduli of bordered Riemann surfaces.

We will consider the B-model from the perspective of string field theory. This is usually referred to as the B-twisted topological field theory, and when coupled to gravity, it becomes the topological string theory. It is localized around constant maps, and near each constant map, we see the “local” string field action. The correspondence goes as in Figure 3.

Here are some developments in the history of describing this new action:

  • •

    Witten described the A-model open string field using Chern-Simons and instanton theories in 1992. As for the B-model open string field, he described it as holomorphic Chern-Simons theory. Finally, he speculated that the theory is actually UV-finite, which we know now is true by the work of M. Wang and J. Yan.

  • •

    The famous work of Bershadsky-Cecotti-Ooguri-Vafa in 1994 described the B-model closed string field theory on a Calabi-Yau threefold as a gauge theory, which they call Kodaira-Spencer gravity. This has some interesting features:

    • –

      At the classical level, the equation of motion describes deformation of complex structures on the Calabi-Yau threefold. By Yau’s proof of the Calabi conjecture, this leads to a family of solutions which are Ricci-flat metrics.

    • –

      The leading cubic vertex of Zwiebach’s string action in the topological B-model admits a full description.

  • •

    There is a construction by Barannikov-Kontsevich which constructs the Frobenius manifold (which encodes classical genus-zero data) of this theory via the geometry of polyvector fields, which will be discussed in the next few lectures.

  • •

    In 2012, the speaker and Kevin Costello gave a mathematical definition of the full string action for the topological B-model on a Calabi-Yau manifold of any dimension and proved that it satisfies the full BV master equation. They refer to this as BCOV theory.

  • •

    In 2015/16, the same authors determined the B-model open-closed quantum coupling in the large N limit and from this perspective they worked out a version of twisted supergravity. Most of the lectures will explain the speaker’s work with Costello.

We will now fix some conventions. We will work with the category of ℤ-graded vector spaces

V=⨁m∈ℤVm.

For any a∈Vm, we will denote its degree by deg⁡(a)=|a|=m. We will denote degree shifts by

(V⁡[n])m=Vm+n,

or namely, shifting to the left. Finally, we will discuss some conventions on tensors. We will denote the symmetric power by

Symn⁡(V)=V⊗n/(a⊗b∼(−1)|a|⁢|b|⁢b⊗a)

and the exterior powers by

Λn⁢(V)=V⊗n/(a⊗b∼−(−1)|a|⁢|b|⁢b⊗a).

These are sometimes referred to as the graded symmetric product and the graded skew-symmetric product. Finally, we will consider the symmetric algebra (or polynomial algebra)

Sym⁡(V)=⨁mSymm⁡(V)

and its completion (a power series ring)

Sym̂⁢(V)=∏mSymm⁡(V).

For a graded algebra A, we will always use [−,−] to refer to the graded commutator, which is defined by

[a,b]=a⁢b−(−1)|a|⁢|b|⁢b⁢a.

Finally, if X is a smooth manifold X, we will write

Ω∙⁢(X)=⨁kΩk⁢(X)

to denote smooth differential forms on X and denote the de Rham differential by d. If X is a complex manifold, we can decompose

Ωk⁢(X)=⨁p+q=kΩp,q⁢(X)

and decompose the differential as d=∂¯+∂.

2 Calabi-Yau geometry

In this section, we will build some foundations for Calabi-Yau geometry. Let X be a complex manifold of dimension dimℂ=d. We will denote the holomorphic tangent bundle by TX.

We will denote polyvector fields by

𝖯𝖵i,j⁢(X)≔Ω0,j⁢(X,Λi⁢TX)

and the space of all polyvector fields by

𝖯𝖵⁡(X)=⨁i,j𝖯𝖵i,j⁢(X).

Locally, we can write μ∈𝖯𝖵i,j⁢(X) can be written as

μ=∑|I|=i|J|=jμJ¯I⁢d⁢z¯I⊗∂zI,

where I={k1,…,ki} and J={s1,…,sj} are multi-indices. Here, the index notation looks like

d⁢z¯J=d⁢z¯s1∧⋯∧d⁢z¯sjand∂zI=∂zk1∧⋯∧∂zki.

These look like differential forms, but are in fact subtly different. All μJ¯I are smooth and skew-symmetric for indices in both I and in J.

There is a natural (wedge) product

𝖯𝖵i1,j1⊗𝖯𝖵i2,j2→∧𝖯𝖵i1+i2,j1+j2

which makes 𝖯𝖵⁡(X) a bi-graded algebra. We will define the total degree by |μ|=i+j for μ∈𝖯𝖵i,j⁢(X). This makes (𝖯𝖵⁡(X),∧) a graded-commutative algebra, namely that α∧β=(−1)|α|⁢|β|⁢β∧α.

We can also extend the ∂¯-operator to polyvector fields, which has degree 1 and goes as

∂¯:𝖯𝖵i,j⁢(X)→𝖯𝖵i,j+1⁢(X).

This is in fact a derivation which satisfies the graded Leibniz rule

∂¯(α∧β)=(∂¯α)∧β+(−1)|α|⁢α∧∂¯β.

There are many definitions for Calabi-Yau manifolds, so we will choose one.

Definition 2.1.

A Calabi-Yau manifold is a pair (X,ΩX) where X is a complex manifold and ΩX is a nowhere-vanishing holomorphic volume form on X.

In local holomorphic coordinates {z1,…,zd} on X, we can write

ΩX=φ⁡(z)⁢dz1∧⋯∧dzd,

where φ⁡(z) is a nowhere-vanishing holomorphic function. The Calabi-Yau form induces a linear isomorphism

𝖯𝖵i,j→⌟⁢ΩXΩd−i,jμ↦μ⁢⌟⁢ΩX.

Unfortunately, we will abuse notation and write ∂ for ∂Ω and whether we mean the divergence operator or the holomorphic de Rham operator will be clear from context. Unfortunately, the divergence operator is not a derivation. The failure is described by the tensor

{α,β}=∂(α∧β)−(∂α)∧β−(−1)|α|⁢α∧(∂β).

This bracket is known in geometry and is related to the Schouten-Nijenhuis bracket [−,−]SN by the sign

[α,β]SN=−(−1)|α|⁢{α,β}.

In mathematics, this is sometimes called the Bogomolov-Tian-Todorov lemma and in physics it is related to the BV algebra. In fact, the difference between the Schouten-Nijenhuis bracket and the BV bracket is related to shifting the degree by 1. The BV bracket has degree given by

{−,−}:𝖯𝖵i1,j1⊗𝖯𝖵i2,j2→𝖯𝖵i1+i2−1,j1+j2.

It is in fact intrinsically defined independent of the choice of volume form (or divergence operator).

The lifting of {−,−} to the volume form ΩX or the divergence operator ∂ is related to BV quantization.

We will now let X be a compact Kähler manifold. The deformation space of complex structures on X is locally given by

ℳ𝖼𝗑={μ∈𝖯𝖵1,1(X)|‖μ‖<ε,∂¯μ+12{μ,μ}=0,∂¯∗μ=0}.

Theorem 2.6 (Bogomolov-Tian-Todorov).

Let X be a compact Kähler Calabi-Yau manifold. Then the deformation space ℳ𝖼𝗑 is smooth and has dimension

dimℂℳ𝖼𝗑=h1⁢(X,TX).

∂¯μ+12⁢{μ,μ}=0

modulo gauge for all types of polyvector fields. We can view the original moduli space as a submanifold of the extended one.

The extended moduli space ℳ is smooth.

Proof.

{α,β} =∂(α∧β)−(∂α)∧β−(−1)|α|⁢α∧(∂β)

{−,−}:ker⁢∂⊗ker⁢∂→Im⁢∂.

3 Period map

Before we move to the B-model, we need to discuss the period map, which will allow us to write down action functionals. Let X,ΩX be a compact Kähler Calabi-Yau manifold. Given μ∈𝖯𝖵1,1⁢(X) satisfying the Maurer-Cartan equation

∂¯μ+12⁢{μ,μ}=0,

we will use [Xμ]∈ℳ𝖼𝗑 to denote the complex manifold specified by the deformation μ. Assume that {zi} are local holomorphic coordinates on X. We can write

μ=∑i,jμȷ¯i⁢d⁢z¯j⊗∂zi.

Then we can define new holomorphic 1-forms by

(dzi+μ⁢⌟⁢dzi) =dzi+∑jμȷ¯i⁢d⁢z¯j
=eμ⁢⌟⁢dzi,

and these form a local basis of (1,0)-forms on Xμ.

Let ℋd denote the complex vector bundle over ℳ𝖼𝗑 whose fiber at [Xμ] is the de Rham cohomology Hd⁢(Xμ). This bundle admits a flat connection, called the Gauss-Manin connection, and denoted by ∇𝖦𝖬, which identifies the nearby fibers to the central one as

Hd⁢(Xμ)≃Hd⁢(X).

There is some global issue with monodromy, but locally the identification is canonical. We now define the holomorphic subbundles (the Hodge filtration) ℱp⁢ℋd⊂ℋd with fibers

ℱp⁢ℋd|[Xμ]=⨁k≥pHk,d−k⁢(Xμ).

In particular, there is the line bundle L=ℱd⁢ℋd which picks up the holomorphic volume form on Xμ. In physics, this is known as the vacuum line bundle. Later, we will see that invariants of the B-model are actually sections of powers of this line bundle.

The period map is locally given by the map

ℳ𝖼𝗑↪ℙ⁡(Hd⁢(X,ℂ))[Xμ]↦[ΩXμ].

Here, we need to use the Gauss-Manin connection to identify the cohomology of Xμ with that of X. The period map is actually a local embedding (the local Torelli theorem). Sometimes it is helpful to remember the actual volume form, and if we consider the ℂ×-bundle

ℳ^𝖼𝗑=Tot⁡(L∖{0})

over ℳ𝖼𝗑, then a point here represents a pair (X,ΩX), so we have defined the local moduli of deformations of a pair (X,ΩX). This allows us to lift the period map to an embedding

ℳ^𝖼𝗑↪Hd⁢(X,ℂ)(Xμ,ΩXμ)↦[ΩXμ].

Our goal is to understand the geometry of the period map, which will allow us to understand the action functional of the B-model. We will begin with the case of Calabi-Yau threefolds, which is classical, and then move to a more modern perspective. Let (X,ΩX) be a Calabi-Yau threefold. Then H3⁢(X,ℂ) has a symplectic pairing given by

ω⁡(α,β)=∫Xα∧β.

Considering the Hodge filtration, the subspace

F2⁢H3=H3,0⊕H2,1⊂H3

is a Lagrangian subspace. Over the moduli space ℳ𝖼𝗑 ω defines a fiberwise symplectic pairing on ℋ3 which is flat with respect to the Gauss-Manin connection. Then we can lift the Hodge filtration to a subbundle

ℱ2⁢ℋ3⊂ℋ3,

which gives a holomorphic family of Lagrangian subspaces.

Proposition 3.1.

The embedding ℳ^𝖼𝗑↪H3 defines a Lagrangian submanifold.

Proof.

Let Ωs be a holomorphic family of Calabi-Yau forms parameterized by s. By Griffiths transversality, we see that

∇𝖦𝖬Ωs⊂ℱ2⁢ℋ3.

Every fiber is a linear Lagrangian subspace, so we are done. □

From this data, we can cook up B-model invariants as follows. Choose a Lagrangian splitting ℒ⊂H3⁢(X,ℂ) be a transversal linear Lagrangian subspace such that

H3=F2⁢H3⊕ℒ

is an isotropic splitting. This allows us to identify

H3≅T∗⁢F2,

where we use F2 to refer to F2⁢H3. Then ℳ^𝖼𝗑 is a Lagrangian submanifold as in Figure 4. Therefore, there is some function F^0∈𝒪⁡(F2) such that ℳ^𝖼𝗑 is the graph of d⁢F^0.

Example 3.2.

Choose ℒ=H1,2⊕H0,3 (the complex conjugate splitting). Physicists would now write down some special geometry and prepotentials. We parametrize ℳ^𝖼𝗑 by

ℳ^𝖼𝗑={(t0,ti⁢∂tiF^0,∂t0F^0)}.

Because ℳ𝖼𝗑=ℳ^𝖼𝗑/ℂ×, we see that F^0 has homogeneous degree 2. The local coordinates on ℳ𝖼𝗑 are given by τi=tit0. Therefore, we can write

F^0=(t0)2⁢ℱ0⁢(τi).

Geometrically, F^0 actually defines a local section of L⊗−2, where L is the vacuum line bundle. We can now reparaterize the extended moduli space by

ℳ^𝖼𝗑={t0⁢(1,τi⁢∂τiℱ0,2⁢ℱ0−τi⁢∂τiℱ0)}.

The factor inside the parentheses is called the primitive period map. We now obtain a particular choice of holomorphic volume form on the moduli space given by

[Ωτ]=(1,τi,∂τiℱ0,2⁢ℱ0−τi⁢∂τiℱ0).

We are now finally able to calculate the Yukawa coupling for the moduli space by

Ci⁢j⁢k⁢(τ) =∫∇∂τi𝖦𝖬[Ωτ]∧∇∂τj𝖦𝖬∇∂τk𝖦𝖬⁡[Ωτ]
=∂τi∂τj∂τkℱ0⁢(τ).

In the physics literature, ℱ0⁢(τ) is called the prepotential.

Before we proceed, we need to describe the deformation of the pair (X,ΩX). We know that deformations of X are given by μ∈𝖯𝖵1,1⁢(X) satisfying the Maurer-Cartan equation

∂¯μ+12⁢{μ,μ}=0.

In the complex structure Xμ specified by μ, the elements

eμ⁢⌟⁢dzi=dzi+μ⁢⌟⁢dzi

form a new basis of (1,0)-forms on Xμ.

Lemma 3.4.

We have

eμ⁢⌟⁢(α∧β)=(eμ⁢⌟⁢α)∧(eμ⁢⌟⁢β)

for any differential forms α,β.

The lemma now implies that

eμ⁢⌟⁢(dz1∧⋯∧dzd)

is of type (d,0) with respect to Xμ. Applying this globally, the form

eμ⁢⌟⁢ΩX

is of type (d,0) in Xμ. Therefore, there exists a smooth function ρ such that

eρ⁢eμ⁢⌟⁢ΩX

is a holomorphic volume form on Xμ. Because the type is (d,0), then the form is holomorphic if and only if it is closed, or in other words that d⁡(eρ⁢eμ⁢⌟⁢ΩX)=0. This gives us the two equations

{∂¯μ+12⁢{μ,μ}=0↝deform to ⁢Xμ∂¯ρ+∂μ+{μ,ρ}=0↝deform to ⁢ΩXμ

which govern deformations of the pair (X,ΩX). These equations were studied by Barannikov in his work on variations of semi-infinite Hodge structures.

4 Extended period map

Introduce a formal parameter t of degree 2, which will play the role of gravitational descendents and consider the combined differential

Q=∂¯+t⁢∂.

We can rewrite our two equations as the single equation

Q⁢μ^+12⁢{μ^,μ^}=0,

where we have defined

μ^=μ+t⁢ρ.

Introduce a new (shifted) dg Lie algebra

(𝖯𝖵⁡(X)⁢⟦t⟧,Q=∂¯+t⁢∂,{−,−}).
Remark 4.1.

The data of (𝖯𝖵⁡(X)⁢⟦t⟧,Q) can be viewed as a homological replacement of volume-preserving (divergence-free) vector fields (ker⁢∂,∂¯). We may now write the complex

ker⁢∂→𝖯𝖵→t⁢∂t⁢𝖯𝖵→t⁢∂t2⁢𝖯𝖵→⋯

which behaves badly, so we replace it with (𝖯𝖵⁢⟦t⟧,Q).

Remark 4.2.

The variable t plays the role of gravitational descendants (namely ψ-classes on the A-side) in the B-model.

Remark 4.3.

If (𝖯𝖵,∂¯,{−.−}) gives extended moduli for X, then (𝖯𝖵⁡⟦t⟧,Q,{−,−}) gives extended moduli for the Calabi-Yau geometry.

Remark 4.4.

The variable t can be viewed as an equivariant parameter for rotation on the worldsheet in the worldsheet B-model.

Question 4.5.

Can we express the above equations as the variational critical locus of some action functional?

One reason we would be interested in this question is because this is the usual approach to classical physics, and then we can quantize these using path integrals. This is unfortunately highly nontrivial, and on a Calabi-Yau threefold, BCOV work with some μ∈ker⁢∂. They found that the Maurer-Cartan equation

∂¯μ+12⁢{μ,μ}=0

is equivalent to δ⁢𝖪𝖲δ⁢μ=0 for the Kodaira-Spencer action 𝖪𝖲.

Warning 4.6.

This approach unfortunately violates locality for various reasons:

  • •

    ker⁢∂ is not a module over C∞⁢(X);

  • •

    One of the terms in 𝖪𝖲 is nonlocal.

Consider the Calabi-Yau geometry and let μ∈𝖯𝖵⁡(X)⁢⟦t⟧. We can ask for an action functional whose critical points are solutions of

Q⁢μ+12⁢{μ,μ}=0.

Unfortunately, the speaker was unable to find this, but there is some magic involved. If we perform an L∞ transformation, this equation becomes

Q⁢μ+∑k≥21k!⁢ℓk⁢(μ⊗k)=0,

and for this equation there is a BCOV action which was found by Costello and the speaker. The L∞ transformation is produced directly from the period map.

Definition 4.7.

Define

𝖲⁡(X)≔𝖯𝖵⁡(X)⁢((t))⁢[2],

where the shift makes μ+t⁢ρ have degree 0. Then define

𝖲+⁢(X)≔𝖯𝖵⁡(X)⁢⟦t⟧⁢[2]and𝖲−⁢(X)≔t−1⁢𝖯𝖵⁢(X)⁢[t−1]⁢[2].

This makes 𝖲⁡(X)=𝖲+⁢(X)⊕𝖲−⁢(X), and once we define a symplectic structure it will be a splitting by isotropic subspaces. However, Q does not preserve the splitting, but this will lead to the classical master equation.

We define a t-sesquilinear pairing on 𝖲⁡(X) (inspired by the higher residue pairing of Kyoji Saito)

ω:𝖲⁡(X)⊗𝖲⁡(X)→ℂ

by the formula

ω⁡(f⁡(t)⁢α,g⁡(t)⁢β)≔Trα⁢β⁢Rest=0⁡f⁡(t)⁢g⁡(−t)⁢dt.

Observe that

ω⁡(g⁡(t)⁢β,f⁡(t)⁢α) =Trβ⁢α⁢Rest=0⁡g⁡(t)⁢f⁡(−t)⁢dt
=−(−1)|α|⁢|β|⁢Trα⁢β⁢Rest=0⁡f⁡(t)⁢g⁡(−t)⁢dt
=−(−1)|α|⁢|β|⁢ω⁢(f⁡(t)⁢α,g⁡(t)⁢β).

If we calculate the degrees, then ω is only nontrivial when

deg⁡(f⁡(t)⁢α)+deg⁡(g⁡(t)⁢β) =deg⁡(α∧β)+deg⁡f⁡(t)+deg⁡g⁡(t)
=2⁢d−2,

so if we take the original shift by 2 into account, we have proved the following result.

Proposition 4.8.

The space (𝖲⁡(X),ω) has a (6−2⁢d)-shifted symplectic structure.

Remark 4.9.

For a Calabi-Yau threefold X, we have the splitting

Ω3=Ω3,0⊕Ω2,1⊕Ω1,2⊕Ω0,3,

and the we will be able to identify this with

t⁢𝖯𝖵0,0⊕𝖯𝖵1,1⊕t−1⁢𝖯𝖵2,2⊕t−2⁢𝖯𝖵3,3

via contraction with ΩX, which we will call Γ. The higher residue pairing will be identified with the usual pairing on differential forms. We should note however that this only works for threefolds.

Proof.

We now consider the (cochain) period map

𝒫:𝖲+⁢(X)→𝖲⁡(X)μ↦t⁡(1−eμ/t).

This 𝒫 is understood as a map on formal schemes. For any Artinian ring (R,𝔪), we send

This truncates at finite order, so the map is well-defined.

We compute the tangent map at μ=0, and we see

This map is actually an L∞-morphism

5 Classical BCOV action

We will begin with a toy model to describe the geometry of gravitational descendants. Suppose the case when X is a point. In this case, 𝖲=ℂ⁡((t)), 𝖲+=ℂ⁢⟦t⟧, and 𝖲−=t−1⁢ℂ⁢[t−1]. The symplectic pairing is given by

Under the identification 𝖲=T∗⁢𝖲+, we write the image of the period map as the graph of dI0 for some I0∈𝒪⁡(𝖲+). We will parameterize τ∈𝖲+ as

Denoting this by φ⁡(τk), we will try to find its geometry. This actually becomes a combinatorial problem, but this actually becomes too complicated. Instead, it can be charcterized by various properties, which correspond to properties of the Lagrangian cone in Gromov-Witten theory.

The first property is the string equation. Let t^:𝖲→𝖲 be the operator which sends tk↦tk+1. Now define

L−1=t^−1,

which is essentially multiplying by t−1. We can view L−1 as a vector field on 𝖲, which is actually symplectic, namely satisfying the equation

ω⁡(L−1⁢f,g)=−ω⁡(f,L−1⁢g).

Writing the symplectic form as

ω =∑k≥0dτk∧dτ−k−1⁢(−1)k+1
=12⁢∑i+j=−1(−1)j⁢dτi∧dτj,

ιL−1⁢ω =∑i+j=−1(−1)j⁢τi+1⁢dτj
=12⁢d⁢(∑i+j=0(−1)j⁢τi⁢τj).

Therefore, we will write the Hamiltonian as

h−1=12⁢τ02+∑k≥1(−1)k⁢τk⁢τ−k.

The following result is one of the basic results in the Givental formalism.

Lemma 5.1.

The vector field L−1 is tangent to the object Im⁢𝒫−t, which is known as the dilaton shift.

Proof.

Let α=𝒫⁡(f)−t=−t⁢eft. We calculate the tangent space

Tα⁢(Im⁢𝒫−t) ={−δ⁢f⁢ef/t}
=𝖲+⁢ef/t.

12⁢τ02+∑k=0∞τk+1⁢∂∂τk⁢I0−∂∂τ0⁢I0=0.

∂∂τ0⁢I0=12⁢τ02+∑k=0∞τk+1⁢∂∂τk⁢I0,

which is exactly the string equation from Gromov-Witten theory.

The second property we will consider is the dilaton equation. Consider the operator

L0:𝖲→𝖲tk↦(k+12)⁢tk.

This is also a symplectic operator satisfying

h0=∑k=0∞(k+12)⁢(−1)−k−1⁢τk⁢τ−k−1.

Note that all of our operators are linear, so the Hamiltonians are quadratic.

The vector field L0 is tangent to Im⁢𝒫−t.

Proof.

We can once again write the Hamilton-Jacobi equation, which says that

∑k=0∞(k+12)⁢(−1)−k−1⁢τk⁢τ−k−1|Im⁢𝒫−t=0.

32⁢∂∂τ1⁢I0=∑k=0∞(k+12)⁢τk⁢∂∂τk⁢I0,

which is exactly the dilaton equation from Gromov-Witten theory. We may continue this and write down the classical Virasoro constraints, but we will stop here.

There is a third equation, called the grading equation. Consider the degree operator

G:𝖲→𝖲tk↦(2⁢k−2)⁢tk.

Here, we are remembering that there is actually a shift by 2 that we have been suppressing and that t has degree 2.

Lemma 5.3.

G is tangent to the Lagrangian Im⁡𝒫 (with no dilaton shift).

Unfortunately, this is not a Hamiltonian vector field (in particular the symplectic form has a nonzero degree). The lemma is equivalent to the statement that Im⁢𝒫 is preserved by the ℂ×-action taking tk↦λ2⁢k−2⁢tk. In particular, we see that I0⁢(τk) is homogeneous of degree 6 if we assign deg⁡τk=2−2⁢k. Combining this with the string and dilaton equations, it is easy to show the following.

Proposition 5.4.

For each k1,…,kn, we have

∂∂τk1⁢⋯⁢∂∂τkn⁢I0|τ=0=∫ℳ¯0,nψ1k1⁢⋯⁢ψnkn=(n−3k1,…,kn).

The general case follows easily from the point case, and in particular we can determine the classical BCOV action. 6 Hodge structure and primitive forms

We can pass our picture from the cochan level to cohomology (or really the Maurer-Cartan functor). We will let

ℳX={μ∈𝖲+⁢(X)|Q⁢μ+12⁢{μ,μ}=0}/gauge equivalence.

The extended period map

𝒫:ℳX↪H∙⁢(𝖲⁡(X),Q)

then we see an isotropic subspace

H∙⁢(𝖲+⁢(X),Q)⊂H∙⁢(𝖲⁡(X),Q).

7 Classical master equation

Recall the period map as in Figure 5. Using the string and dilaton equations, we determined that Im⁢𝒫 was the graph of dI0X, where

I0X⁢(μ)=Tr⁡⟨eμ⟩0.

Our goal now will be to study some structure relating to Q, which will allow us to pass to a finite-dimensional model. Q is odd (whereas the Virasoro constraints are even), so we will write down an odd version of the Hamilton-Jacobi equation, which will be the classical master equation.

Because Q preserves ω, we will write down the quadratic Hamiltonian hQ, which will satisfy hQ|Im⁢𝒫=0. The differential Q=∂¯+t⁢∂ satisfies Q2=0, and is therefore a cohomological vector field. Here are some properties of the operator Q:

  • •

    It preserves 𝖲+⁢(X);

  • •

    It does not preserve 𝖲−⁢(X).

To give an idea of the general picture and how to quantize the theory, we will consider a finite-dimensional toy model. Let

(V,ω,Q)

be a dg (even) symplectic vector space (and for simplicity, we will assume the degree is 0), so in particular we can consider one of

ω∈Λ2⁢V∗orω−1∈Λ2⁢V.

By definition, the differential Q is skew-symmetric with respect to ω. Assume that we have a splitting

V=V+⊕V−,

where both V+ and V− are Lagrangian subspaces. We will require that Q preserves V+ but not necessarily V−. The splitting will allow us to make the identification V=T∗⁢V+ and consider the projection

π+:V→V+.

We know that ω−1∈Λ2⁢V⊂(V+⊗V−)⊕(V−⊗V+). To write down the Hamiltonian function, consider

(Q⊗1)⁢ω−1∈(V+⊗V−)⊕(V−⊗V+)⊕(V+⊗V+).

Denote the component in V+⊗V+ by

P=(π+⊗π+)⁢[(Q⊗1)⁢ω−1]∈V+⊗V+,

which plays the role of the BV kernel and measures the failure of Q to preserve V−.

Proposition 7.1.

P defines a degree 1 element of Sym2⁡(V+) and is Q-compatible, namely that

(Q⊗1+1⊗Q)⁢P=0.
Proof.

Using the fact that Q is skew-symmetric with respect to ω, we see that

(Q⊗1+1⊗Q)⁢ω−1=0.

This implies that

(Q⊗1)⁢ω−1∈Sym2⁡(V)

is symmetric, and projecting to V+⊗V+ concludes the proof. □

This is actually a dual description of the Hamiltonian function hQ. Geometrically, we can consider

(Q⊗1)⁢ω−1∈Sym2⁡(V)→𝜔Sym2⁡(V∗)∋hQ,

which exactly gives the quadratic Hamiltonian associated to Q. Using the fact that

(Q⊗1)⁢ω−1∈(V+⊗V−)⊕(V−⊗V+)⊕Sym2⁡(V+),

we see that

hQ∈(V−∗⊗V+∗)⊕(V+∗⊗V−∗)⊕Sym2⁡(V−∗).

We see that the Hamilton-Jacobi equation will have a linear term coming from the first two components and a quadratic term coming from the last component.

Because (Q⊗1+1⊗Q)⁢P=0, we see that [Q,∂P]=0. The rest of the properties are straightforward to check. □

Now assume that we have a Lagrangian submanifold

We will now return to our original infinite-dimensional setting of the B-model on a Calabi-Yau manifold X. The structure is a bit more complicated but is still similar. Recall that

ω(−,−)=Tr(−,−)Rest=0(−⋅−).

The problem comes from the trace pairing, which causes the Poisson tensor ω−1 to involve distributions as

where δΔ is a distributional element of 𝖯𝖵⁡(X)⊗𝖯𝖵⁡(X) and is the integral kernel for the identity operator

Note that this is fine classically but will presernt problems for quantizing the theory. We can still write down the BV kernel

P =(π+⊗π+)⁢[(Q⊗1)⁢ω−1]

because Q only fails to preserve 𝖲−⁢(X) on t−1⁢𝖯𝖵 via the t⁢∂ term. Given a local functional I on 𝖲+⁢(X)=𝖯𝖵⁡(X)⁢⟦t⟧ of the form I=I⁡(μk)=∫⋯, its variation can be computed as

9 Homotopic renormalization

In quantum theory, we will replace (V+,Q) by ℰ,Q, where ℰ is the space of fields. Usually, we will take

ℰ=Γ⁡(X,E∙)

to be the global (smooth) sections of some graded vector bundle and

Q:ℰ→ℰ

to be an elliptic operator (for example ∂¯ or ∂). This data (ℰ,Q) will be called an elliptic complex. The (shifted) symplectic space will be replaced by a (shifted) Poisson kernel P, which is a distributional section of Sym2⁡(ℰ) which is usually supported on the diagonal of X×X (here, note that P comes from the inverse of integration, which involves delta functions).

We will now follow the toy model until we reach an obstruction. The first modification we need to make is to force ℰ∗=Hom𝖼𝗈𝗇𝗍⁡(ℰ,ℂ) to be the continuous dual (these are essentially distributions on X). The next modification we need is to consider that ℰ∗ is a nuclear space, so when we write ℰ∗⊗ℰ∗, we mean the completed tensor product, which we think of as distributions on X×X. This allows us to define

Symn⁡(ℰ∗)⊂(ℰ∗)⊗n.

We may now discuss functions on ℰ as

𝒪⁡(ℰ)=∏n≥0Symn⁡(ℰ∗).

Our next goal is to define the BV operator, which in the toy model was

∂P:Symn⁡(V+∗)→Symn−2⁡(V+∗).

We would like to define

∂P:Symn⁡(ℰ∗)→Symn−2⁡(ℰ∗),

but this is not well-defined because we cannot pair two distributions, which in QFT is known as the ultraviolet problem and arises in any infinite-dimensional model.

We will resolve this problem by using Costello’s homotopic renormalization theory. We will change notation and replace P by K0∈𝖣𝗂𝗌𝗍⁡(Sym2⁡(ℰ)), which is the (shifted) Poisson kernel. This is Q-closed, namely that

Q⁡(K0)=(Q⊗1+1⊗Q)⁢K0=0.

The key observations are

  1. (1)

    K0 is a Q-closed distribution;

  2. (2)

    Elliptic regularity means that

    H∙⁢(𝖲𝗆𝗈𝗈𝗍𝗁,Q)≅H∙⁢(𝖣𝗂𝗌𝗍𝗋𝗂𝖻𝗎𝗍𝗂𝗈𝗇𝗌,Q)

    and therefore we can write

    K0=Kr+Q⁡(Pr),

    where Kr is a smooth kernel and Pr is a distribution known as the parametrix.

We will call Kr the renormalized BV kernel with respect to the parametrix Pr. Now, we can define

∂Kr:Symn⁡(ℰ∗)→Symn−2⁡(ℰ∗)

by contracting with the smooth kernel Kr. This is now well-defined and gives us a renormalized BV operator

∂Kr:𝒪⁡(ℰ)→𝒪⁡(ℰ).

(Note that working with formal power series means we are working perturbatively, and the non-perturbative theory is much more complicated). Because Kr is Q-closed, we see that

[Q,∂Kr]=0.
Definition 9.1.

The data (𝒪⁡(ℰ),Q,∂Kr) defines a dGBV algebra called the renormalized dGBV with respect to the parametrix Pr.

10 Quantum BCOV theory

We are finally ready to discuss the quantum B-model. Recall that our space of fields is

ℰ=𝖲+⁢(X)=𝖯𝖵⁡(X)⁢⟦t⟧⁢[2]

Calculations are very hard, but we can do them using UV finiteness and locality. In practice, constructing a quantization is very complicated, but the program usually goes as follows.

  1. (1)

    I𝖢𝖳⁢(ε)∈ℏ⁢𝒪𝗅𝗈𝖼⁢(ℰ)⁢⟦ℏ⟧

    exists. If we can find the counterterms, the family {I⁡[L]} automatically satisfies the homotopic RG flow. However, it does not necessarily satisfy the quantum master equation.

  3. (3)

    Find further corrections to solve the quantum master equation. This step may be obstructed, and the obstruction is known in physics as the gauge anomaly.

and will have integration, the Hodge decomposition, and non-linear structures (products) all be well-behaved. It is given by

𝖯𝖵f,∞(X)={μ∈L2(𝖯𝖵(X))||∇f|j∇jμ∈L2 for all i,j}.
Definition 11.7.

The data (X,g,Ω) (here g is a complete Kähler metric) is called a bounded Calabi-Yau geometry if (X,g) is a bounded geometry (namely a complete Riemannian manifold, all derivatives of curvature are bounded, and positive injectivity radius), and all covariant derivatives of Ω and Ω−1 are bounded.

Definition 11.8.

Let (X,g) be a bounded geometry. A holomorphic function f:X→ℂ is strongly elliptic if for all ε>0 and k≥2, then ε⁢|∇f|k−|∇kf|→+∞ as z→∞ approaches the boundary.

12 Open-closed B-model

So far, we have discussed the B-model closed string field. This leads to a generalized version of BCOV theory, which was developed by Costello and the lecturer. We will now discuss the open-closed B-model. As a reminder, Witten in 1992 gave two models of the open string field theory.

  • •

    The A-model open string field is Chern-Simons theory with instanton corrections;

  • •

    The B-model open string field is holomorphic Chern-Simons theory.

Let X be a Calabi-Yau threefold and E be a holomorphic vector bundle on X. The space of fields will be

ℰ=Ω0,∙⁢(X,End⁡(E))⁢[1]∋A

and the action (in the BV formalism) is given by

𝖧𝖢𝖲⁡[A]=∫XTr⁡(12⁢A∧∂¯A+16⁢A∧[A,A])∧Ω.

If we decompose

A=A0+A1+A2+A3,

where Ai∈Ω0,i⁢(X,End⁡(E)), then A0 is the ghost, A1 is the gauge (physical) field, A2 is the anti-field, and A3 is the anti-ghost. For the physical field A1, the equation of motion is

∂¯A1+12⁢[A1,A1]=0,

which says that if we set ∇¯=∂¯+A1, then ∇¯2=0, meaning ∇¯ defines a new holomorphic vector bundle structure on E. This is what is meant when it is said that holomorphic Chern-Simons theory describes the moduli of holomorphic vector bundles.

The space ℰ is (−1)-shifted symplectic with the symplectic form

ω⁡(α,β)=∫XTr⁡(α∧β)∧Ω.

The shifted Poisson kernel is given by

ω−1=δΔ∈𝖣𝗂𝗌𝗍⁡(ℰ⊗ℰ)

and defines a BV bracket {I1,I2}o for local functionals I1,I2. Holomorphic Chern-Simons theory satisfies the classical master equation

{𝖧𝖢𝖲,𝖧𝖢𝖲}o=0.

If we write δ𝖧𝖢𝖲={𝖧𝖢𝖲,−}o (the BRST transformation), then we obtain

δ𝖧𝖢𝖲⁢A=∂¯A+12⁢[A,A],

and this implies that δ𝖧𝖢𝖲2=0. Equivalently, this says that Ω0,∙⁢(X,End⁡(E)) is a dg Lie algebra.

A bit more universally, embed E↪L⊕N as a subbundle for some sufficiently ample line bundle L. This allows us to represent E by some idempotent matrix

P∈𝔤⁢𝔩N⁢(C∞⁢(X))

by choosing a smooth splitting. Using this, we write E=P⁡(L⊕N), and then we can embed

Ω0,∙⁢(X,End⁡(E))↪Ω0,∙⁢(X,𝔤⁢𝔩N).

Here, N must be very large, so we will consider the behavior as N→∞. We will focus on

ℰn=Ω0,∙⁢(X)⊗𝔤⁢𝔩N⁢[1]⊂ℰn+1⊂⋯

and look for functionals on ℰN which have a stable expression when N→∞. We will call these admissible functionals.

Example 12.1.

is admissible.

We will now study the large N limit from the perspective of large N duality. For A∈ℰN, we can write

𝖧𝖢𝖲=∫XTr⁡(12⁢A∧∂¯A+13⁢A3)∧Ω.

Unlike ordinary Chern-Simons theory (which only allows us to tune the coupling constant), holomorphic Chern-Simons has many degrees of freedom to deform. One deformation is to deform the Calabi-Yau structure, and in fact this gives all deformations. Consider a first order deformation

𝖧𝖢𝖲→𝖧𝖢𝖲+J,

where J is an admissible local functional. The first-order classical master equation says that

δ𝖧𝖢𝖲⁢J={𝖧𝖢𝖲,J}o=0.

J is the local dual of Lie algebra homology

H∙𝖫𝗂𝖾⁢(𝔤⁢𝔩N⁢Ω0,∙⊗𝔤⁢𝔩N),

where the differential is ∂¯ and the Lie bracket is given by [−,−]. This looks hard to compute, but in fact there is a way to compute it.

Theorem 12.2 (Loday-Quillen-Tsygan).

The large N limit of the Lie algebra homology is given by

limN→+∞H∙⁢(𝔤⁢𝔩N⁢(R))=Sym⁡(𝖧𝖢∙−1⁢(R)).

Here, 𝖧𝖢 is called cyclic homology.

Applying this to our model, we obtain

𝖧𝖢∙⁢(Ω0,∙⁢(X)) ≃(Ω∙,∙⁢(X)⁢[t−1],∂¯+t⁢∂)
=(Ω∙,∙⁢(X)⁢((t−1))/t⁢Ω∙,∙⁢(X)⁢⟦t−1⟧,∂¯+t⁢∂)

by the Hochschild-Kostant-Rosenberg theorem (use 𝖧𝖢∙⁢(R)∼(C∙⁢(R)⁢[t−1],b+t⁢B)). By the trace pairing, this is local dual to

(𝖯𝖵⁡(X)⁢⟦t⟧,Q=∂¯+t⁢∂).

Therefore, the BCOV field (topological gravity) is the single trace operator at N→+∞ (this is also related to the AdS/CFT correspondence) in the gauge/gravity duality.
